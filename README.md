# ClipViewer

**描きかけの .clip 原稿を、書き出さずにそのまま「読者視点」で読むための Windows 用ビューワー**

## コンセプト

Clip Studio Paint でマンガを描いていると、「いま描いている原稿を、読者と同じ目線で読み直したい」という欲求が必ず発生します。しかし——

- CSP で開くと、それは「編集画面」であって「読書体験」ではない
- 読者目線で読むには PNG 等への書き出しが必要で、修正のたびに書き出し直すのは現実的でない
- そもそも .clip を直接開ける汎用ビューワーが存在しない

ClipViewer はこの隙間を埋めるために作られました。**原稿フォルダの .clip 連番を、そのまま全画面・見開き・右綴じでめくる。** 気になるコマを見つけたら Ctrl+E でそのページが CSP で開く。「読む → 直す」のループを最短にするための道具です。

原稿ビューに限らず、AI生成画像の大量チェック(埋め込みプロンプトのプレビュー、縮小時のモアレ軽減)、zip/rar 化した既刊の読書(アーカイブ直読み+前回の続きから再開)など、**キーボード主体で画像を大量に流し見る用途**全般に向きます。

## 主な機能(ざっくり)

- **.clip / .psd の直接表示**(書き出し不要)、jpg / png / gif / webp / avif、アニメGIF・アニメWebP再生
- **見開き表示** — 右綴じ/左綴じ、表紙の単独表示、横長ページの自動単独化
- **アーカイブ直読み** — zip / cbz / rar / lzh / 7z の中の画像をそのまま閲覧、前回の閲覧位置から自動再開
- **シークバー** — 画面下端にマウスを寄せると出現する読了バー。任意ページへジャンプ
- **モアレ軽減+シャープ化フィルタ** — 縮小表示時のスクリーントーンの干渉縞を抑制(F9/F11でトグル)
- **ズーム** — 原寸100%とFitに自動スナップ。回転・反転、マルチモニタ指定
- **外部エディタ連携** — Ctrl+E で表示中のファイルを CSP 等で開く

機能の完全な仕様・全キーバインド一覧は [docs/ClipViewer_統合要件定義書.md](docs/ClipViewer_統合要件定義書.md) にあります。

## 設定はすべて ini ファイルで

ClipViewer に設定画面(GUI)はありません。**細かい設定はすべて、exe と同じフォルダに自動生成される `ClipViewer.ini` をテキストエディタで編集して行います**(デフォルトでは **F2 キー**で即座に開けます)。

| 弄れるもの | 例 |
|---|---|
| キーバインド | 全機能のキーを変更可。カンマ区切りで複数割り当ても可(`NextPage=Left,A`) |
| マウスバインド | 戻る/進む/ホイールクリックボタンに任意の機能を割り当て |
| フィルタ調整 | `[Filters]` セクションでモアレ軽減の強度、シャープ化の半径・強度・閾値など |
| 動作設定 | 表示モニタ番号、ページスキップ枚数、保存先フォルダ、アーカイブ履歴の保持件数など |

ini の各項目にはコメントで説明が付いています。設定を壊してしまったら ini を削除すれば、次回起動時にデフォルト値で再生成されます。

## 動作環境

- Windows 10 / 11(.NET Framework 4.6 以降 — Win10 以降は標準搭載)
- AVIF 表示には Microsoft Store の「HEIF 画像拡張機能」+「AV1 Video Extension」
- rar / lzh / 7z の閲覧には 7-Zip のインストールが必要(zip / cbz は不要)

## 導入と使い方

1. [Releases](../../releases) から zip をダウンロードして任意のフォルダに展開
2. 画像ファイルを `ClipViewer.exe` にドラッグ&ドロップ(または拡張子を関連付け)
3. `←→` ページ送り / `Space` 見開き切替 / `F1` 情報表示 / `Esc` 終了

## 免責・注意事項

- `.clip` の読み取りは**非公式なフォーマット解析**に基づきます。CELSYS 社とは無関係で、CSP の更新で動かなくなる可能性があります
- 動作検証は **CSP Ver.1.x（買い切り版）で生成した .clip** で行っています。Ver.2.x〜4.x（サブスク版）のファイルも同じ内部構造（SQLite + プレビューPNG）と報告されており読める見込みですが、未検証です。読めないファイルはスキップされます（クラッシュはしません）
