# ClipViewer

**描きかけの .clip 原稿を、書き出さずにそのまま「読者視点」で読むためのビューワー**

Clip Studio Paint の `.clip` ファイルを直接開ける Windows 用画像ビューワーです。
連番の原稿フォルダを、全画面・見開き・右綴じでめくる——つまり「自分のマンガを読者として読み直す」ために作りました。
CSP で開くと編集画面になってしまい、PNG に書き出すのは面倒。そのすき間を埋める道具です。

## 特徴

- **.clip / .psd を直接表示**（書き出し不要。.clip は内部プレビューを抽出）
- jpg / png / gif / webp / avif 対応（アニメ GIF / アニメ WebP 再生可）
- zip / cbz / rar / lzh / 7z アーカイブ内の画像を直接閲覧（前回の続きから自動再開）
- 見開き表示（右綴じ/左綴じ・表紙単独・横長ページ自動単独）
- シークバー（画面下端ホバーで出現、読了バー式）
- モアレ軽減フィルタ（縮小表示時の網点干渉縞を Lanczos-3 で抑制）+ シャープ化フィルタ
- ズーム（原寸100%とFitに自動スナップ）・回転・反転・マルチモニタ指定
- 全キーバインド・マウスボタンを ini でカスタマイズ可能（F2 で即編集）
- **Ctrl+E で表示中のファイルを CSP 等の外部エディタで開く**（読んでいて気になった箇所を即修正）

## 動作環境

- Windows 10 / 11（.NET Framework 4.6 以降 — Windows 10 以降は標準搭載）
- AVIF 表示には Microsoft Store の「HEIF 画像拡張機能」+「AV1 Video Extension」が必要
- rar / lzh / 7z の閲覧には 7-Zip（`7z.exe`）のインストールが必要（zip / cbz は不要）

## 使い方

1. [Releases](../../releases) から zip をダウンロードして任意のフォルダに展開
2. 画像ファイルを `ClipViewer.exe` にドラッグ＆ドロップ（または拡張子を関連付け）
3. `←→` でページ送り、`Space` で見開き切替、`Esc` で終了

主なキー操作（すべて ini で変更可能）:

| キー | 動作 |
|------|------|
| ← / → | ページ送り / 戻り（右綴じ基準） |
| Space | 単ページ / 見開き切替 |
| F3 | 右綴じ / 左綴じ切替 |
| F4 | 表紙の単独表示切替 |
| F1 / Tab | 情報パネル（ファイル名・ページ番号・ズーム率・EXIF） |
| F9 / F11 | モアレ軽減 / シャープ化フィルタ ON/OFF |
| Enter | フルスクリーン / ウィンドウ切替 |
| Home / End / PageUp / PageDown | ジャンプ・複数ページスキップ |
| ↑ / ↓ | 前後のフォルダ（またはアーカイブ）へ移動 |
| Ctrl+E | 外部エディタで開く |
| F2 | 設定ファイル（ClipViewer.ini）を開く |
| Esc | 終了 |

全キーバインド・設定項目の一覧は [docs/ClipViewer_統合要件定義書.md](docs/ClipViewer_統合要件定義書.md) を参照してください。

## ソースからのビルド

Visual Studio 2022（Community 可）で `ClipViewer.sln` を開いて Release ビルドするだけです。
NuGet パッケージ（System.Data.SQLite）は初回ビルド時に復元されます。
アニメ WebP を再生する場合は `libs/` 内の 3 つの DLL（libwebp）を exe と同じフォルダに置いてください。
